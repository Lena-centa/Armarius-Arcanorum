本教程介绍这个工具每天会用到的主要功能,读完大约需要 15 分钟,可以挑需要的章节看。

------------------------------------------------------------
一、这个工具是做什么的?
------------------------------------------------------------

它把你用 ComfyUI 生成过的图片整理成一座"档案库":

  · 自动读取每张图片里记录的信息(模型、LoRA、提示词、
    采样器、种子、分辨率、生成时间……),不需要你手动填写
  · 想找"哪张图用过某个 LoRA""上个月有哪些配方"之类
    的问题,打开浏览器搜索就行
  · 新生成的图片会自动进库,不用手动导入

打开方式:启动服务后,在浏览器地址栏输入
    http://127.0.0.1:8009
就能看到页面。顶部的导航栏有五个页面:

    图片库(默认页,找图用)
    生成(实验功能,见最后一章)
    统计
    标注库
    设置

页面右上角的"☾"按钮可以切换深色/浅色主题。

------------------------------------------------------------
二、开始之前:第一次使用要先做的两件事
------------------------------------------------------------

1. 打开"设置"页面
2. 找到「扫描与 ComfyUI」一组的"扫描根目录",填入你存放
   ComfyUI 生成图片的文件夹,例如  D:\ComfyUI\output
3. 点右下角"保存设置",然后重启服务(关闭窗口重新启动)
4. 重启后系统会自动扫描该文件夹,把图片建进档案库

注意事项:

  · 只有"带 ComfyUI 工作流信息"的图片才会被收录。手机
    截图、普通照片不会出现在库里,这不是故障
  · 如果以后往文件夹里新增图片,系统会定时自动扫描,
    也可以随时在页面里手动触发(见第三章第 4 节)
  · 修改扫描目录不会丢旧数据,新目录只是增量入库
  · 所有数据都保存在本机,图片不会上传到任何地方

------------------------------------------------------------
三、图片库:找图的核心页面
------------------------------------------------------------

图片库页面从上到下分为:搜索栏、筛选区、图片列表。
"一次生成的多张图"会自动归为一批,列表里以批次为单位
显示,可以展开看整批。

3.1 关键词搜索(最常用的功能)

  点击顶部放大镜图标,出现搜索框。支持:

  · 多个关键词:用空格或逗号分隔,也可以每行一个;
    多个关键词会同时匹配(AND 关系)
  · 排除关键词:点搜索框里的"高级搜索"按钮,在
    "排除关键词"里填词,命中任一词的图片会被隐藏
  · 搜索历史:搜索框展开时会显示历史记录,点一下即可
    再次使用,也可以"清空历史"
  · 输入联想:输入时下方会自动联想词条,支持中文。
    例如输入"初音未来"会联想出对应的英文标签,选中
    即填入,不用自己记英文拼写

  技巧:搜索词既可以用英文标签(如 white hair),也
  可以输入自然语言(如"蓝色头发"),系统会尽量帮你
  匹配到正确的词条。

3.2 筛选区(组合使用效果最好)

  · 文件名:按文件名片段过滤
  · 基座模型:下拉框选择模型,只显示用过该模型的图片
  · 实例:只有连接了多个档案库时才会出现,单机使用
    一般看不到
  · LoRA:输入框带候选列表,可以只选一个,也可以输入
    多个;旁边"排除 LoRA"用于排除含某 LoRA 的批次
  · 开始时间 / 结束时间:按生成时间过滤。可以点日历
    图标选择,也可以直接手动输入,例如 2026-08-14 13:25
  · 条数:每页显示 50 / 100 / 200 条,图片多时选 200
    可以减少翻页

  设好条件后点"筛选"按钮生效;筛选条件之间是叠加
  关系(同时满足才显示)。

3.3 列表与批次

  列表里每一行是一个批次,显示:

  · 第一张图的缩略图和文件名
  · 用到的 LoRA(可直接看到,不用点进详情)
  · 采样器、分辨率、批次数
  · 正向 / 负向提示词的摘要
  · 命中的标注(你在"标注库"里加的备注会显示在这里)

  点击行可以展开查看批次的更多信息,点击图片打开
  大图预览(见第四章)。

3.4 数据同步:图片更新与手动扫描

  · 页面右上方有个"状态摘要"按钮,展开后可以看到
    批次总数、日期范围、平均 Steps/CFG,以及数据同步
    状态和"扫描新文件"按钮
  · 当扫描目录里出现新图片时,页面顶部会出现提示条
    "发现新的生成文件",点"刷新列表"即可看到新内容
  · 想立即检查新文件,也可以随时点"扫描新文件"按钮,
    不用等自动扫描

------------------------------------------------------------
四、图片预览与详情
------------------------------------------------------------

点击列表里的图片,会打开一个大图预览窗口。

4.1 基本操作

  · 窗口底部的缩略图条可以快速切换图片
  · 左右两侧的 ‹ › 箭头按钮:上一张 / 下一张
  · 右上角 × 关闭窗口;按键盘 Esc 键也可以关闭

4.2 快捷按钮(窗口右上角)

  · 复制正向 Prompt:一键复制该图的正向提示词,方便
    贴回 ComfyUI 或其他工具
  · 在 ComfyUI 打开:把这张图的工作流发送到 ComfyUI,
    可以直接修改再生成(需要 ComfyUI 正在运行)
  · 节点图:查看工作流节点结构图(需要 ComfyUI 在线
    提供节点信息;ComfyUI 没开时此按钮不显示)
  · 去生成:跳转到"生成"页面(实验功能,见第九章)

4.3 详情侧栏(窗口右侧)

  从上到下依次展示这张图的完整信息:

  · 来源:ComfyUI 或 NovelAI(带"来源"徽标)
  · 路径:图片在电脑里的位置
  · 模型:基座模型
  · LoRA:用到的 LoRA 及强度
  · 提示词:正向 / 负向,按段落分层展示
  · 采样器:采样器参数、种子;多采样器时逐一列出
  · ControlNet:用到的 ControlNet 及参数
  · 区域 / 蒙版:局部重绘等信息
  · NovelAI 图片会多一个"原始 JSON"块,可一键复制
    (NovelAI 的图片信息格式和 ComfyUI 不同,工具
    已经做了专门适配)

4.4 提示词里的标记与 Tag 补全参考(重点功能)

  详情侧栏的提示词文本中,凡是能识别的"标签"都会
  被高亮显示。它的玩法很多:

  · 单击标签:复制该标签文本
  · 鼠标悬停标签(约 0.3 秒):弹出小浮层,显示
    这个标签的参考信息:
      - 类型徽章(角色 / 作品 / 特征 / 画师)和该标签
        在 Danbooru 的帖子数(越热门数字越大)
      - 中文翻译(有中文别名时显示)
      - 相关推荐:按"角色、作品、构图、背景、发色、
        服饰、表情……"分组的推荐标签,每个推荐旁边
        有帖子数
      - 角色特征:悬停"角色"类标签时,会额外显示
        该角色的官方特征(发色、发型、瞳色、服饰等)
      - 识别来源标注:从自然语言句子中识别出的标签
        会标注"识别自 xxx";模糊匹配的标注"模糊匹配"
  · 右键点击标签:打开完整版面板,显示更多推荐
  · 点击推荐标签(chip):自动追加到页面顶部的搜索框,
    方便连续收集关键词后统一搜索
  · 面板操作:
      - 按住面板头部可拖动
      - 点图钉按钮"固定面板"后,面板不会被其他操作
        关闭或替换,适合对照阅读、连续收集标签;
        按 Esc 键可随时关闭
      - 面板底部有"在 Danbooru 查看"链接,可跳转到
        原站查看完整资料
  · 悬停自然语言句子:不必精确知道标签写法,把鼠标
    停在提示词句子的某个词上,工具会取这个词前后共
    最多 7 个词去识别,例如 "the girl is Yumia
    Liessfeldt" 悬停在 Yumia 上,能识别出角色名

  这个功能需要随发布包提供"补全参考数据"。如果数据
  未安装,这些面板会自动隐藏,不影响其他功能。

4.5 补全参考块(批次级推荐)

  在详情侧栏底部,会有一块"补全参考",展示与这张图
  所在批次搭配推荐的标签,来源与 4.4 相同,是导入时
  按整批预计算好的。同样,点击推荐标签会加入搜索框。

------------------------------------------------------------
五、解析图片:单张手动入库
------------------------------------------------------------

顶部导航栏的"解析图片"按钮(上传箭头图标):

  · 点击后选择电脑上的一张图片(支持 png / jpg /
    webp / gif / avif)
  · 系统会读取图片内嵌的工作流信息并加入档案库
  · 适用场景:某张图因为特殊原因没被自动收录,或
    想快速查看一张图用的什么参数

------------------------------------------------------------
六、统计:分析你的"配方"
------------------------------------------------------------

统计页面回答"哪套组合最好用"这类问题。使用方法:

  1. 选择"焦点 LoRA":要分析的 LoRA
  2. 可选:限定基座模型、开始/结束日期
  3. 点"刷新"

  注意:不做选择直接刷新也可以,"LoRA 使用频率"依然
  有数据;但"搭配 LoRA / 搭配 Prompt"两块分析必须
  先选一个焦点 LoRA,否则会提示"请选择焦点 LoRA"。

页面会展示三块结果:

  · 搭配 LoRA:这个 LoRA 常和哪些 LoRA 一起用,
    以及搭配时的样本数
  · 搭配 Prompt:这个 LoRA 常搭配哪些提示词片段
  · LoRA 使用频率:范围内各 LoRA 的使用次数排行

  技巧:想了解"这个 LoRA 配什么最好",固定它看
  搭配 LoRA;想找"最近在流行什么",不选焦点 LoRA、
  只看使用频率排行即可。

------------------------------------------------------------
七、标注库:给组合打上自己的备注
------------------------------------------------------------

图片的参数是自动读取的,但"这个组合当时想画什么、
注意什么"只有你知道。标注库就是用来记录这些的:

  · 点"新建"开始创建一条标注
  · 名称:例如"某角色基础触发词"
  · 分类:自选分类,方便日后筛选
  · LoRA:关联一个或多个 LoRA
  · Prompt 片段:每行一个
  · 备注:写下你想记的话
  · 参考图片:可以搜索并关联几张示例图片
  · 点"保存标注"完成

之后:

  · 图片库里,凡是命中这条标注的批次会显示标记,
    鼠标悬停可看说明
  · 详情页的提示词区也会显示命中的标记
  · 标注库页面支持按分类、LoRA、关键词筛选,
    方便快速查找和修改

------------------------------------------------------------
八、设置
------------------------------------------------------------

设置页面的项目按组排列,一般只需要动最前面的几项:

  · 扫描与 ComfyUI:
      扫描根目录(必配,见第二章)
      ComfyUI 地址(默认 http://127.0.0.1:8188,
      用于"在 ComfyUI 打开"和"生成"功能)
  · 同步 / 备份:自动扫描周期、启动即同步、备份
    等,保持默认即可
  · 近实时入库:ComfyUI 输出目录轮询、缓冲入库,
    保持默认即可
  · 其余(服务端口、MongoDB、SQLite、多网关、
    部署 / Worker):普通用户不需要动

注意事项:

  · 修改后点"保存设置",然后"重启服务"才会生效
  · 改乱了可以点"还原"撤销,或点"查看原始文件"
    直接看配置文件内容
  · 页面顶部的状态摘要会显示配置文件路径、生效状态、
    未保存的修改数量

------------------------------------------------------------
九、生成(实验功能,注意!)
------------------------------------------------------------

"生成"页面可以基于历史图片的工作流,修改参数后
重新提交给 ComfyUI 生成。

重要提醒:

  · 这是实验性功能,处于早期开发阶段,高度不稳定,
    可能存在较多缺陷,即将进行大幅重构
  · 不建议把它作为正式的工作流程依赖;日常请优先
    使用"图片库 / 统计 / 标注库"等查阅与整理功能

目前它的用法大致是:

  1. 在图片库打开某张图,点"去生成"跳转,来源图片
     会自动带入;或在"生成"页手动粘贴来源图片编号
  2. 点"载入"读取工作流,在"工作流编辑"区域修改
     参数
  3. 点"开始生成"提交任务,右下角可打开"当前队列"
     查看运行中 / 排队中的任务
  4. 生成结果可在"生成历史"和结果预览中查看

因为该功能即将重构,具体操作可能很快变化,以上只作
简单说明。

------------------------------------------------------------
十、高效使用小贴士(汇总)
------------------------------------------------------------

  1. 找图先想好条件:关键词 + 基座模型 + LoRA +
     时间范围组合使用,一次筛到位
  2. 多关键词用空格或逗号分隔,不用一次次点筛选
  3. 排除关键词很好用:想找"没戴帽子"的图,在排除
     词里填 hat 即可
  4. 输入联想支持中文,不会英文标签也能搜
  5. 悬停标签看参考、点推荐标签收集关键词,比手动
     拼标签快得多;固定面板后可以连续对照
  6. 看到满意的图,直接"复制正向 Prompt"拿走用
  7. 新图没出现:点"扫描新文件"或看顶部提示条;
     单张图可用"解析图片"手动入库
  8. 常用组合记得在"标注库"打标,日后在图片列表里
     一眼认出
  9. 想研究某个 LoRA,去"统计"页选它做焦点,看它
     的黄金搭档
  10. 深色 / 浅色主题按自己习惯切换;设置修改后
      记得保存并重启服务
